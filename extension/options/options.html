CropCal

Click the CropCal toolbar button (or press Alt/Option+Shift+C), drag a box around an event on any page, and a prefilled Google Calendar event opens for you to review and save.

Setup

  1. Paste the invite code you were given below.
  2. Click Save, then Test connection. That's it.
Each code has a daily crop limit. Your crops are sent to the CropCal service, which forwards them to Google's Gemini API on a paid plan (not used for training) and keeps nothing.
